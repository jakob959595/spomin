# Memory Game

A classic card-matching memory game built with HTML, CSS and JavaScript as a short school project.

## Features
- Flip cards to find matching pairs
- Cards are shuffled randomly at the start of each game
- Move counter / timer / restart button...

## Built With
- HTML
- CSS
- JavaScript

## How to Play
1. Click on a card to reveal it.
2. Click a second card to find its match.
3. Match all pairs to win.
